# Govila Marketplace — Frontend

Estrutura:
- `index.html` — página principal
- `style.css` — estilos e responsividade
- `script.js` — pesquisa, filtros, favoritos, carrinho, menu e GPS
- `images/logo.png` — logotipo fornecido

## Executar
Abra `index.html` no navegador.

## Próxima fase
O frontend já está preparado para receber backend/Firebase:
- autenticação de clientes;
- lojas e produtos reais;
- carrinho persistente;
- pedidos;
- pagamento;
- localização GPS;
- painel do comerciante;
- painel do entregador;
- acompanhamento do pedido em mapa.
